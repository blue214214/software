## 一、通用环境（所有成员）

### 1. Git

**下载安装**

- Windows：https://git-scm.com/download/win，下载安装包，一路默认即可
- macOS：终端执行 `xcode-select --install`，或从官网下载

**验证**

```bash
git --version
# 输出示例：git version 2.43.0
```

**配置**

```bash
git config --global user.name "你的姓名"
git config --global user.email "你的邮箱"
```

---

### 2. Docker Desktop（运行 MySQL / Redis / RabbitMQ）

**下载安装**

- Windows / macOS：https://www.docker.com/products/docker-desktop
- 下载后双击安装，安装完成后启动 Docker Desktop

**验证**

```bash
docker --version
docker compose version
```

**启动基础服务**

在项目根目录执行：

```bash
docker compose up -d
```

启动后三个服务均可用：
- MySQL：`localhost:3306`，用户名 `canteen`，密码 `canteen123`
- Redis：`localhost:6379`
- RabbitMQ 管理界面：http://localhost:15672，用户名/密码均为 `canteen`/`canteen123`

**停止服务**

```bash
docker compose down
```

## 二、成员2：C++ 后端

### 1. 开发工具下载安装

两款 IDE 选其一即可，不需要同时安装。

#### 选项 A：Visual Studio Code（推荐，免费）

- 下载：https://code.visualstudio.com/
- 安装后在扩展市场搜索并安装以下插件：
  - `C/C++`（Microsoft）
  - `CMake Tools`（Microsoft）
  - `clangd`（可选，代码补全更智能）

#### 选项 B：CLion（功能更强，需付费）

- 下载：https://www.jetbrains.com/clion/
- 学生可免费申请教育授权：https://www.jetbrains.com/student/
- CLion 原生支持 CMake，无需额外安装插件，调试体验比 VSCode 更好
- 如果不想付费，直接用 VSCode 即可

---

### 2. 依赖项安装

#### 2.1 编译器与构建工具

**Windows（推荐使用 MSYS2）**

1. 下载 MSYS2：https://www.msys2.org/
2. 安装后打开 MSYS2 UCRT64 终端，执行：

```bash
pacman -Syu
pacman -S mingw-w64-ucrt-x86_64-gcc \
          mingw-w64-ucrt-x86_64-cmake \
          mingw-w64-ucrt-x86_64-ninja \
          mingw-w64-ucrt-x86_64-pkg-config
```

**macOS**

```bash
xcode-select --install          # 安装 clang
brew install cmake ninja
```

**验证**

```bash
cmake --version   # 需要 3.20+
g++ --version     # 或 clang++ --version
```

---

#### 2.2 vcpkg（C++ 包管理器，用于安装所有依赖库）

```bash
# 克隆 vcpkg
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg

# Windows
./bootstrap-vcpkg.bat

# macOS / Linux
./bootstrap-vcpkg.sh
```

**设置环境变量**（见第3节）

---

#### 2.3 安装项目依赖库（通过 vcpkg）

在 vcpkg 目录下执行：

```bash
# Drogon（C++ Web 框架）
./vcpkg install drogon

# OpenSSL（JWT 签名）
./vcpkg install openssl

# jwt-cpp（JWT 库，header-only）
./vcpkg install jwt-cpp

# hiredis（Redis 客户端）
./vcpkg install hiredis

# AMQP-CPP（RabbitMQ 客户端）
./vcpkg install amqpcpp

# libev（AMQP-CPP 依赖的事件循环）
./vcpkg install libev

# jsoncpp（JSON 解析，Drogon 自带但可单独安装）
./vcpkg install jsoncpp
```

> 安装 Drogon 时会自动安装大部分依赖，耐心等待约 10-20 分钟。

---

### 3. 环境变量配置

#### Windows（MSYS2 环境）

在 `~/.bashrc` 或 `~/.bash_profile` 中添加：

```bash
# vcpkg 工具链
export VCPKG_ROOT="/path/to/vcpkg"
export PATH="$VCPKG_ROOT:$PATH"

# MSYS2 编译器（如果使用 MSYS2）
export PATH="/ucrt64/bin:$PATH"
```

#### macOS

在 `~/.zshrc` 或 `~/.bash_profile` 中添加：

```bash
export VCPKG_ROOT="$HOME/vcpkg"
export PATH="$VCPKG_ROOT:$PATH"
```

修改后执行 `source ~/.zshrc` 使其生效。

### 4. Hello World 工程测试

创建一个最小 Drogon 项目验证环境是否正确。

**步骤一：创建目录**

```bash
mkdir hello_drogon && cd hello_drogon
```

**步骤二：创建 `main.cc`**

```cpp
#include <drogon/drogon.h>

int main() {
    drogon::app()
        .addListener("0.0.0.0", 8080)
        .registerHandler("/hello",
            [](const drogon::HttpRequestPtr& req,
               std::function<void(const drogon::HttpResponsePtr&)>&& cb) {
                auto resp = drogon::HttpResponse::newHttpResponse();
                resp->setBody("Hello, BJTU Canteen!");
                cb(resp);
            })
        .run();
    return 0;
}
```

**步骤三：创建 `CMakeLists.txt`**

```cmake
cmake_minimum_required(VERSION 3.20)
project(hello_drogon CXX)
set(CMAKE_CXX_STANDARD 17)

find_package(Drogon CONFIG REQUIRED)

add_executable(hello_drogon main.cc)
target_link_libraries(hello_drogon PRIVATE Drogon::Drogon)
```

**步骤四：编译运行**

```bash
mkdir build && cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
cmake --build . --config Release
./hello_drogon        # Windows: hello_drogon.exe
```

**步骤五：验证**

打开浏览器访问 http://localhost:8080/hello，看到 `Hello, BJTU Canteen!` 即表示环境搭建成功。

## 三、成员1：Flutter 移动端

### 1. 开发工具下载安装

#### Flutter SDK

1. 访问 https://flutter.dev/docs/get-started/install
2. 选择对应操作系统，下载 Flutter SDK 压缩包
3. 解压到合适目录，例如：
   - Windows：`C:\flutter`
   - macOS：`~/flutter`

#### Android Studio（必须，提供 Android SDK 和模拟器）

- 下载：https://developer.android.com/studio
- 安装时勾选 `Android SDK`、`Android Virtual Device`

#### Visual Studio Code（可选，轻量编辑器）

- 安装后在扩展市场搜索安装：
  - `Flutter`（Dart Code）
  - `Dart`（Dart Code）

---

### 2. 依赖项安装

#### Android SDK

打开 Android Studio → SDK Manager，安装：
- Android SDK Platform 33（Android 13，用于模拟器）
- Android SDK Build-Tools 33.x
- Android Emulator

#### Flutter 依赖检查

```bash
flutter doctor
```

按照输出提示逐项修复，直到所有项显示绿色 ✓。

常见问题修复：
- `Android toolchain` 报错：在 Android Studio 中接受 SDK 许可证
  ```bash
  flutter doctor --android-licenses
  ```
- `Xcode` 报错（macOS）：
  ```bash
  sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
  ```

---

### 3. 环境变量配置

#### Windows

1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
2. 在 `Path` 中新增：`C:\flutter\bin`
3. 新建变量 `ANDROID_HOME`，值为 Android SDK 路径，例如：
   `C:\Users\用户名\AppData\Local\Android\Sdk`

#### macOS

在 `~/.zshrc` 中添加：

```bash
export PATH="$PATH:$HOME/flutter/bin"
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$PATH:$ANDROID_HOME/tools:$ANDROID_HOME/platform-tools"
```

执行 `source ~/.zshrc` 生效。

### 4. Hello World 工程测试

**测试 RabbitMQ 连接**

确保 Docker 已启动（`docker compose up -d`），然后创建 `test_mq.py`：

```python
import pika

connection = pika.BlockingConnection(
    pika.ConnectionParameters(
        host='localhost',
        port=5672,
        credentials=pika.PlainCredentials('canteen', 'canteen123')
    )
)
channel = connection.channel()
channel.queue_declare(queue='hello_test')
channel.basic_publish(exchange='', routing_key='hello_test', body='Hello BJTU!')
print("消息发送成功！")
connection.close()
```

运行：

```bash
python test_mq.py
# 输出：消息发送成功！
```

**测试 MySQL 连接**

创建 `test_db.py`：

```python
import sqlalchemy as sa

engine = sa.create_engine(
    "mysql+pymysql://canteen:canteen123@localhost:3306/canteen_db"
)
with engine.connect() as conn:
    result = conn.execute(sa.text("SELECT 1"))
    print("数据库连接成功！结果：", result.fetchone())
```

运行：

```bash
python test_db.py
# 输出：数据库连接成功！结果：(1,)
```

两个测试均通过，即表示 Python 开发环境搭建成功。

## 附录：常见问题

| 问题 | 解决方法 |
|------|----------|
| `cmake` 找不到 Drogon | 确认 `-DCMAKE_TOOLCHAIN_FILE` 指向 vcpkg 工具链文件 |
| Docker 启动失败 | 确认 Docker Desktop 已运行，端口 3306/6379/5672 未被占用 |
| `flutter doctor` 报 Android 许可证问题 | 执行 `flutter doctor --android-licenses` 全部输入 `y` |
| Python `pika` 连接 RabbitMQ 失败 | 确认 Docker 已启动，检查用户名密码是否为 `canteen`/`canteen123` |
| MSYS2 找不到 vcpkg 安装的库 | 确认 `CMAKE_TOOLCHAIN_FILE` 路径正确，使用正斜杠 `/` |
